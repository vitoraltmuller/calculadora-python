# 🧮 Calculadora em Python

Uma calculadora desenvolvida em Python para praticar lógica de programação, funções e estruturas de decisão (`match/case`).

## Funcionalidades

* Soma
* Subtração
* Multiplicação
* Divisão
* Tratamento de divisão por zero
* Resultado formatado com duas casas decimais

## Tecnologias

* Python 3

## Como executar

```bash
python calculadora.py
```

## Objetivo

Projeto desenvolvido durante meus estudos em Ciência e Tecnologia na UFABC como prática de programação em Python.
